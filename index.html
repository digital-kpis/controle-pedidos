Configurar sincronização (Firebase, opcional)
Por padrão os dados ficam salvos apenas neste navegador (localStorage). Para sincronizar entre dispositivos/turnos em tempo real, crie um projeto no Firebase Console, ative o Firestore Database (modo produção) e preencha o objeto FIREBASE_CONFIG no início do script deste arquivo com as credenciais do seu app web (Configurações do projeto → Seus apps → SDK do Firebase). Sem isso o dashboard funciona normalmente, só que só neste aparelho.
